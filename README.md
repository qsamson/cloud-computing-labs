# Cloud Computing Technologies

**Fall 2026 — [Cloud Computing Technologies (ITMO-444 | ITMO-544)](https://iit.instructure.com/courses/26047)**

This repository contains my laboratory work, technical setup, experiments, and course projects for **Cloud Computing Technologies**. The repository documents hands-on work with cloud platforms, containerized environments, cloud-native development tools, and deployment technologies used throughout the course.

## Course Learning Outcomes

Upon completion of this course, students will be able to:

1. Explain, document, and implement the fundamental aspects of **IaaS, PaaS, and SaaS**.
2. Use and administer **industry-standard cloud resources**.
3. Correctly identify **cloud-native operations and development methodologies**.
4. Build and deploy **elastic scaling applications** on a cloud platform.
5. Design applications using a **cloud-native architecture**.
6. Describe and employ **web technologies for software deployment**.
7. Implement course concepts to develop and deploy a **cloud-based web application built on a microservice architecture that uses a third-party API**.
